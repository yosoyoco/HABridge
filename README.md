# HABridge

HABridge controls preamp gain and +48 V for compatible preamps directly from the **PREAMP** section of eMotion LV1.

It supports Behringer WING, Behringer X32 and Midas M32 consoles used with compatible SoundGrid interfaces or cards.

## Compatibility

- Behringer WING, X32 and M32
- Compatible SoundGrid interfaces and cards
- Windows
- macOS on Intel and Apple Silicon

See the [user guide](GUIDE.md) and [supported versions](SUPPORTED_VERSIONS.md).

## Installation

1. Install the Waves module required by the SoundGrid interface.
2. Install HABridge, then associate each SoundGrid device with its console in HABridge Control.
3. In LV1, assign the SoundGrid devices and patch their inputs to the required channels.

Download HABridge from [Releases](../../releases).

## +48 V

Before enabling or recalling +48 V, verify the microphone, source and cabling connected to the preamp.
