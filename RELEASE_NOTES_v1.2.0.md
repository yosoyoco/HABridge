# HABridge 1.2.0

HABridge 1.2.0 adds support for DN32-WSG and improves compatibility with current Waves SoundGrid installations.

## What's new

- Added DN32-WSG support for compatible X32/M32 systems.
- Added DN32-WSG support on Windows and macOS.
- Improved compatibility with Waves v17 SoundGrid control modules.
- WING, X-WSG and DN32-WSG modules are identified from their installed SoundGrid module information rather than a fixed module file fingerprint.
- macOS DN32 support is Universal for Intel and Apple Silicon.

## Notes

- Original Waves SoundGrid modules must already be installed.
- HABridge does not include or redistribute Waves modules.
- Close eMotion LV1 before installing or updating HABridge.

Before enabling or recalling +48 V, verify the microphone, source and cabling connected to the preamp.
